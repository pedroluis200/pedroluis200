## 👨‍💻 Sobre mí

Graduado de **Ingeniería Informática (2022)**. Me dedico a construir cosas que funcionan: **bots de Telegram**, **webs** y **herramientas** que resuelven problemas concretos, sobre todo en la automatización.

- 🤖 Diseño bots de Telegram
- 🌐 Desarrollo proyectos web ligeros y rápidos, pensados para móvil
- 📱 Creo apps para seguimiento de mercado, con alertas y calculadoras
- 🏋️ Hago aplicaciones de ejercicio físico para gimnasios
- ⚡ Trabajo en entornos con conectividad limitada, así que optimizo para que todo funcione con poco ancho de banda y tolere cortes
- 🎯 **Busco trabajo remoto** como desarrollador, automatizador y soporte técnico

> *"Si algo se hace más de dos veces, merece un script."*
